# TanStack Start

TanStack Start uses Vinxi under the hood and supports standard fetch handlers.

### 1. Install

```sh
npm install eridu-tech hono
```

### 2. Create the handler

```ts file=./tanstack_start-samples/create_handler.ts
```

**File structure**

```
.
├── app
│   └── routes
│       └── api
│           └── $.ts
├── package.json
└── app.config.ts
```

### 3. Develop

```sh
npm run dev
```

### 4. Build

```sh
npm run build
```

**Reference:** [TanStack Start API Routes](https://tanstack.com/start/latest/docs/framework/react/api-routes)
